# src/experiments/layouts/

Layout and navigation-flow experiments live here, one folder per idea:
`src/experiments/layouts/<slug>/` with `Component.tsx` + `meta.ts` (+ optional `README.md`,
`controls/`, co-located sub-components). Auto-discovered by `src/lib/registry.ts` — no
registration step.

Standalone component ideas go in `src/experiments/components/` instead. Copy
`src/experiments/_template/` to start.
